Mac Whisper Captions

A zero-cost, high-accuracy, ultra-low-latency local live captioning platform for Apple Silicon Macs.

Features

  • Local Processing: Runs entirely on your machine using whisper.cpp.
  • Metal Accelerated: Takes full advantage of Apple Silicon (M1/M2/M3) GPU for real-time transcription.
  • OBS Ready: Transparent web overlay ready to be added as a Browser Source in OBS.
  • Zero API Costs: No cloud dependencies. No subscriptions.
