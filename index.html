Mac Whisper Captions

A zero-cost, high-accuracy, ultra-low-latency local live captioning platform for Apple Silicon Macs.

How It Was Built (Step-by-Step Installation)

If you want to know exactly how this platform was constructed from scratch, here are the steps we took:

  1. Initial Setup: Created the project directory, initialized `package.json`, and set up the `public` and `server` folders.
  2. C++ Compiler (CMake): Installed cmake via Homebrew (brew install cmake) as it's required for compiling modern C++ applications.
  3. Whisper.cpp Engine: Wrote a shell script (scripts/build-whisper.sh) to clone the ggerganov/whisper.cpp repository and download the lightweight ggml-base.en.bin AI model.
  4. Audio Dependencies (SDL2): Installed the SDL2 audio library (brew install sdl2) because the real-time stream binary requires it to directly access hardware microphones.
  5. Metal GPU Compilation: Compiled the `whisper-stream` binary using CMake with Apple Silicon GPU acceleration enabled (-DGGML_METAL=ON -DWHISPER_SDL2=ON).
  6. Node.js Middleware: Built server/index.js to spawn the C++ binary in a child process. The script reads the terminal output, filters out blank audio/silence, and broadcasts the live text over a fast WebSocket on port 3000.
  7. Web Overlay Frontend: Created public/index.html as a transparent overlay with CSS themes, connecting seamlessly to the WebSocket for OBS integration.

Features

  • Local Processing: Runs entirely on your machine using whisper.cpp.
  • Metal Accelerated: Takes full advantage of Apple Silicon (M1/M2/M3) GPU for real-time transcription.
  • OBS Ready: Transparent web overlay ready to be added as a Browser Source in OBS.
  • Zero API Costs: No cloud dependencies. No subscriptions.
