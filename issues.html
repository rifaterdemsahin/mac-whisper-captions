Historical Issues & Fixes Ledger

A chronological record of the technical hurdles encountered while building the local captioning system, and the architectural solutions used to fix them.

OBS Stacking Lines / Not Syncing with Live Preview FIXED

The Problem: The Control Panel live preview showed single, beautifully updating lines, but OBS Studio stubbornly continued to stack duplicate sentences on top of each other.

The Cause: OBS Studio has an incredibly aggressive internal browser cache. Even though we updated the deduplication logic in public/app.js, OBS was secretly holding onto the old version of the script in its memory!

The Fix:
  1. Added a "cache-buster" query parameter to the HTML tag: <script src="app.js?v=2"></script>. This forces OBS to discard the cache and download the newest script.
  2. Manual Override: In OBS, double-click your Browser Source, scroll to the bottom, and click the "Refresh cache of current page" button.

Subtitles Flickering & Duplicating (Sliding Window Stacking) FIXED

The Problem: Speaking "One, two, three" would output three separate stacked lines ("One", "One two", "One two three") instead of seamlessly updating a single line.

The Cause: The Whisper AI uses a sliding audio window and constantly emits "partial" progressing transcripts before finalizing them.

The Fix:
  • Server Side: Modified server/index.js to extract the exact start-timestamp of the segment and broadcast it as a unique Segment ID.
  • Client Side: Upgraded the frontend JS to track lines by their Segment ID. Instead of appending new HTML elements, the client now targets the specific Segment ID and performs an in-place string update, eliminating all flicker.

[BLANK_AUDIO] Hallucination Spam FIXED

The Problem: Whisper aggressively hallucinates tags like [BLANK_AUDIO] or Subtitles by Amara.org during periods of dead silence.

The Cause: The initial regex filter was only inspecting text inside timestamped blocks. Occasionally, Whisper outputs raw system text without a timestamp, allowing it to bypass the filter.

The Fix: Restructured the Node server to funnel 100% of standard output through a centralized aggressive Regex cleaner that strips all brackets [], parentheses (), and asterisks **, completely silencing environmental noise tags.

Subtitles Staying on Screen Forever FIXED

The Problem: Text remained permanently visible on the screen until you spoke again to push it upwards.

The Fix: Implemented a fadeTimeout in JavaScript. If no WebSocket text is received for 5000ms, the CSS opacity smoothly transitions to 0, clearing the screen.

Wrong Default Microphone / Scarlett Routing FIXED

The Problem: The C++ engine defaults to Device 0 (usually the Mac's built-in microphone), requiring manual switching every time.

The Fix: Built a startup intelligence routine in the Node server that parses the C++ diagnostic stream, scans for any hardware containing the word "Scarlett", and instantly re-routes the AI stream to it automatically.
